# Namedle

A Wordle spin-off where players guess names instead of words!

## Setup
1. Clone this repo onto your local machine by either using `git clone https://github.com/alantao5056/Namedle.git` or by downloading this repo as a zip
2. Run main.exe by typing `./main.exe` in the terminal
3. Enjoy the game!

## How to play Namedle
1. Enter the length of the name you want to guess. For example, type `5` then press enter if you want to guess a five letter name.
2. Enter the number of guesses you need. If you don't guess the word in that many tries, the game will reveal the answer.
3. Guess a name and Namedle will give you a string of hints with the same length as your word. `.` means the letter is in the correct place, `o` means the letter is in the wrong place, and `x` means that there is no such letter in the name.
4. You can choose to play again with different parameters or quit.
